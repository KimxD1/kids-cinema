# 🎬 꼬마 영화관 예매 (교육용 실시간 좌석 예매 견본)

유아 교육용 실시간 영화관 예매 사이트 견본입니다. 30석(5행 × 6열), 결제/취소, 실시간 좌석 잠금을 지원합니다.

## 기술 구성
| 구분 | 사용 기술 | 이유 |
|---|---|---|
| 서버 | C# / ASP.NET Core 8 | 이미 아는 C# 사용, 웹서버 내장 |
| 실시간 통신 | SignalR (ASP.NET Core 기본 포함) | WebSocket 자동 처리, 재연결 자동 |
| 화면 | HTML + CSS + JavaScript (단일 파일) | 어떤 기기에서도 브라우저만으로 접속 |

## 실행 방법
1. [.NET 8 SDK](https://dotnet.microsoft.com/download) 설치
2. 이 폴더에서 터미널을 열고
   ```bash
   dotnet run
   ```
3. 출력에 나오는 주소(예: `http://localhost:5000`)를 브라우저 **두 개 탭**으로 열어 보세요.
   한 탭에서 좌석을 누르면 다른 탭에서 즉시 "다른 친구가 선택 중"(빨강)으로 바뀝니다.

## 동작 규칙
- **선택(노랑)**: 나만 볼 수 있는 임시 점유. 다른 사람에게는 빨강(선택 불가)으로 보임.
- **5분 안에 결제하지 않으면** 자동으로 선택이 풀립니다. (`SeatStore.HoldDuration`)
- **브라우저를 닫으면** 선택 중이던 좌석이 즉시 풀립니다. (`OnDisconnectedAsync`)
- **결제**: 4자리 예매번호 발급 → 좌석이 회색(예매 완료)으로 바뀜. 실제 결제는 없습니다.
- **취소**: 예매번호 입력 → 좌석이 다시 초록(선택 가능)으로 돌아감.
- 두 사람이 동시에 같은 좌석을 눌러도 서버의 `lock` 때문에 한 명만 성공합니다.

## 파일 설명
```
CinemaBooking/
├─ Program.cs                  서버 시작 설정
├─ Hubs/SeatHub.cs             브라우저 ↔ 서버 실시간 통신 (좌석 선택/해제/결제/취소)
├─ Services/SeatStore.cs       좌석 30석의 상태 저장 + 동시성 처리 (핵심 로직)
├─ Services/HoldExpiryService.cs  선택 시간 만료 자동 처리
└─ wwwroot/index.html          아이들이 보는 화면
```

## 집에서 접속하게 하려면 (인터넷 공개)
서버가 24시간 켜져 있어야 하므로 무료 호스팅을 사용하세요.
- **Azure App Service (F1 무료)** — C# 프로젝트와 가장 궁합이 좋음. GitHub 저장소 연결 시 push만 하면 자동 배포.
- **Render / Railway / Fly.io** — Dockerfile 한 개로 배포 가능.
> 좌석 상태는 메모리에만 저장되므로 서버가 재시작되면 초기화됩니다. 교육용에는 오히려 편리하지만,
> 유지가 필요하면 SQLite 저장을 추가하세요.
